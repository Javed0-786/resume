## 🔄 How to Update the Resume (Best Practice)

To update the resume without breaking any external links or needing to redeploy the portfolio:

1. Replace `Javed_Alam_Resume.pdf` with the new version (keep the exact filename).
2. Commit and push to `main`:
   ```bash
   git add Javed_Alam_Resume.pdf
   git commit -m "Update resume with latest experience"
   git push origin main
   ```
3. Any website, portfolio button, or recruiter bookmark pointing to this repository will automatically serve the updated version!
